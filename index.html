Brain-inspired computation

Memory, spikes, criticality, phase transitions — the classical models behind neuromorphic computing and the 2024 Nobel Prize in Physics. Six demos sharing one substrate.

Hopfield Retrieval
Patterns encoded in dense edge weights via Hebbian learning. A noisy initial state converges to the nearest stored memory in 2–5 synchronous steps. Pick the cue, set the noise, watch the recall.
open →
Hopfield Capacity (α_c Phase Transition)
Same machinery as Hopfield, but with P random patterns. Walk the load α = P/N across the critical line at α_c ≈ 0.138 (Amit–Gutfreund–Sompolinsky 1985–87). Below: stored patterns are fixed points. Above: spin-glass phase, capacity broken.
open →
Modern Hopfield (Attention-Equivalent)
Replace classical Hopfield's quadratic energy with log-sum-exp. Capacity jumps from 0.138·N to exponential in N, and the resulting retrieval rule IS Transformer attention (Ramsauer et al. 2020). The bridge between Hopfield 1982 and ChatGPT.
open →
Spiking Neurons (LIF Network)
Leaky integrate-and-fire neurons on a 2D lattice — the simplest spiking model from Lapicque 1907, still the standard for modern neuromorphic chips. A drive at the centre triggers radial waves of synchronised spikes. Crank coupling for runaway "epilepsy", drop it for localised oscillation.
open →
Neural Avalanches (Self-Organised Criticality)
Bak–Tang–Wiesenfeld sandpile on a 2D grid. Drive slowly: most events are tiny, occasional ones sweep across the grid. Avalanche sizes follow a power law — the same s^(−3/2) statistics Beggs & Plenz 2003 found in cortical slices. The strongest evidence that brains operate near a critical point.
open →
Ising Model (2D Lattice)
The classical statistical-mechanics model. Spins on a square lattice align with neighbours under thermal noise; second-order phase transition at T_c ≈ 2.269 (Onsager 1944). Drag the temperature slider live across the critical point.
open →

Pattern formation

Reaction–diffusion: two interacting species, two diffusion rates, and an instability that produces stripes, spots, mitosis, gliders. The same chemistry on a graph, on a lattice, with different topology — different patterns.

Network Turing Patterns
Reaction–diffusion on a graph. When the inhibitor diffuses much faster than the activator, the network splits into high / low clusters. Hubs become pattern organizers.
open →
Classical Turing (Brusselator)
The original 1952 Turing mechanism on a 2D lattice. Two species, two diffusion rates; the homogeneous state goes unstable and stripes / spots appear from arbitrarily small noise. Same chemistry as the network Turing demo, different topology.
open →
Gray–Scott on a 2D Grid
Reaction–diffusion on a square lattice. Spots, mazes, mitosis, worms — the same two equations produce wildly different patterns depending on (f, k).
open →

Adaptive networks

Where the topology itself coevolves with the dynamics on it — edges rewire, weights shift, and the structure becomes a dependent variable. The smallest section so far; more demos welcome (issues / PRs).

Adaptive Voter (Holme–Newman)
Edges rewire when neighbors disagree; opinions copy when they don't. Echo chambers form above a critical rewire rate. The structure of the network co-evolves with the opinions on it.
open →
Adaptive SIS Epidemic (Gross–D'Lima–Blasius)
Susceptible nodes can rewire away from infected neighbours. Topology coevolves with the disease — bistability and hysteresis appear that don't exist on a fixed graph. Watch the network self-quarantine around the infected cluster.

Curated reading paths

Three short sequences of demos for a coherent week of teaching or self-study. Each path moves from a familiar starting point to a frontier question — pick one, work through the three demos in order with the "For instructors" prompts in each player panel.

1. Phase transitions

A phase transition is when a system undergoes a qualitative change in macroscopic behaviour as one control parameter is varied. The same mathematical structure (energy minimisation on spins, with thermal or load-driven competition) reappears under very different physical interpretations.

  1. Ising — temperature drives the canonical 2D transition. Tc ≈ 2.269 known exactly (Onsager 1944): calibrate intuition against ground truth.
  2. Hopfield Capacity — pattern load α drives a different transition (memory → spin glass). Same substrate, different control parameter.
  3. Neural Avalanches — no external control parameter; the system self-tunes to a critical line. Power-law avalanches are the signature.

Arc: from textbook (exact answer) to derived (analytic) to contested (active methodological debate).

2. Network ≠ grid

ABM tools default to spatial lattices, but real systems (brain, social, ecological) live on graphs with non-trivial degree distributions. The same dynamics on a grid versus a graph can produce qualitatively different macroscopic phenomena.

  1. Classical Turing (Brusselator) — activator-inhibitor chemistry on a 2D lattice. Stripes and spots from local diffusion.
  2. Network Turing Patterns — the same chemistry on a random graph. Hub-organised clusters instead of stripes. Direct visual evidence that topology matters.
  3. Adaptive SIS Epidemic — now the topology itself coevolves with the dynamics. Bistability and hysteresis appear that do not exist on a static graph.

Arc: lattice → graph → coevolving graph. Each step removes one assumption about what the substrate is.

3. Memory & computation

A 38-year arc from Hopfield's 1982 PNAS paper to the modern equivalence between Hopfield retrieval and transformer attention. Three demos compress the math behind a substantial chunk of contemporary AI.

  1. Hopfield Retrieval — Hopfield 1982: patterns stored in dense Hebbian weights, recall by energy descent. Memory as a dynamical attractor.
  2. Hopfield Capacity — AGS 1985-87: capacity αc ≈ 0.138·N is a true second-order phase transition. The first quantitative limit on the original model.
  3. Modern Hopfield — Ramsauer et al. 2020: log-sum-exp energy gives exponential capacity, and the retrieval rule IS transformer attention. The bridge from 1982 PNAS to ChatGPT.

Arc: 1982 → 1987 → 2020. The same substrate, three milestones, the connection to attention reframes the entire history.
